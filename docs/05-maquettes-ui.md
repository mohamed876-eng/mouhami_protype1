## 6. Palette Couleurs

```
BLEU FONCÉ (Principal)
  #1E3A5F  ┃ Fond sidebar, headers, boutons principaux
  #2B4F7C  ┃ Hover
  #152B47  ┃ Active

BLANC (Arrière-plan)
  #FFFFFF  ┃ Fond principal, cartes
  #F8F9FB  ┃ Fond alterné, sidebar items

GRIS CLAIR (Secondaire)
  #E8ECF1  ┃ Bordures, séparateurs
  #D1D7E0  ┃ Inputs, disabled
  #9AA6B8  ┃ Texte secondaire

TEXTE
  #1A1A2E  ┃ Texte principal
  #4A5568  ┃ Texte secondaire

ACCENT (Notifications, Alertes)
  #E53E3E  ┃ Urgent, alerte rouge
  #38A169  ┃ Succès, validé
  #D69E2E  ┃ Attention, en attente
```

## 7. Responsive Breakpoints

| Taille | Largeur | Comportement |
|--------|---------|--------------|
| Mobile | < 768px | Sidebar cachée (hamburger), cartes en colonne |
| Tablet | 768-1024px | Sidebar réduite (icônes), grille 2 colonnes |
| Desktop | > 1024px | Sidebar complète, grille 3-4 colonnes |
